# require

## Purpose

Store a single requirements document that becomes input to specs and contracts.

## What belongs here

- `require.md` (single requirements document created by /qfai-require)

## What does not belong here

- multiple competing requirement files
- API/DB/UI design details (use contracts)
- implementation plans (use specs/delta)

## Checklist

- [ ] Requirements are written in a testable way
- [ ] At least one non-functional requirement is included
- [ ] Open Questions are listed separately from decisions
