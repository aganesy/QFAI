## Authoring rules

- A term earns an entry when two specs would otherwise define it differently,
  or when a reader outside the team would guess wrong.
- `Not to be confused with` is where the value is. A definition that no one
  would have misread did not need this file.
- Use the term consistently in every spec once it is defined here. Introducing a
  synonym is a glossary change, not a wording choice.
- Domain vocabulary only — do not restate framework or language terms.
