# 04 Capability

## Capability Map

| Capability ID | Description | KPI Link |
| ------------- | ----------- | -------- |
| CAP-0001 | Create an order draft | draft creation success rate |
| CAP-0002 | Prevent duplicate draft creation | duplicate prevention correctness |

## Hypotheses

- If draft creation is fast and explicit, operator errors decrease.
- If duplicate outcomes are deterministic, support escalation decreases.
