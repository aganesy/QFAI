# report

## Purpose

`.qfai/report/` stores derived outputs generated during validation and preflight.

These artifacts are reporting outputs, not SSOT.

## Typical files

- `validate.json` (generated by `qfai validate`)
- `run-YYYYMMDDhhmmssSSS/run.json` (validate run metadata)
- `run-YYYYMMDDhhmmssSSS/validator.json` (validate findings snapshot)
- `run-YYYYMMDDhhmmssSSS/traceability.json` (traceability snapshot)
- `run-YYYYMMDDhhmmssSSS/summary.md` (human-readable run summary)
- `atdd-traceability/summary.json` (ATDD annotation traceability summary)
- `atdd-traceability/summary.md` (ATDD annotation traceability markdown report)
- `report.md` / `report.json` (generated by `qfai report`)
- `preflight_summary.md` (generated before SDD artifact authoring)

## Rules

- Keep this directory as report-only output.
- Do not move requirement/spec SSOT into this directory.
- If `preflight_summary.md` exists, treat it as review-exempt context for the next SDD step.
- Keep generated artifacts excluded via the project root `.gitignore` managed
  block (managed by `qfai init`).
- The root `.gitignore` is expected to ignore at least:
  - `.qfai/report/*`
  - `.qfai/review/*`
  - `.qfai/evidence/*`
- Recommended root managed block:

  ```gitignore
  # ── QFAI managed (generated by qfai init) ──
  .qfai/report/*
  !.qfai/report/README.md
  .qfai/evidence/*
  !.qfai/evidence/README.md
  .qfai/discussion/discussion-*/
  .qfai/review/*
  !.qfai/review/README.md
  ```

- `qfai validate` / CI already guard this expectation via the review-artifacts
  checks and the init/gitignore test suite. When `.qfai/` 下のローカル
  `.gitignore` を削除・統合する変更を入れる場合は、root managed block が
  残っていることを必ず確認する。
- If those root ignore entries are missing, generated outputs in this
  directory may be committed unintentionally.
