- 変更対象は YAML ファイルおよびマークダウンファイルのみ（バイナリ・データベース変更なし）。
- git による差分管理が標準的に機能する。

ただし、明示的なロールバック手順（例：`review-roster.yml` の特定エントリ削除手順）が spec 内に記載されていない点は改善の余地がある。
