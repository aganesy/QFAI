### CHG-003 (Assistant-layer Recut + Work-log Surface, 2026-05-22)

| Term                      | Meaning                                                                                                                                                                                                                                                   |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| assistant-layer recut     | `.qfai/assistant/{instructions,steering,manifest}` の 3-directory split を 4 conceptual layer (Constitution / Manifest / Catalog / Steering) + Process partition に再分割する v1.9.0 の構造変更。                                                         |
| Constitution layer        | `.qfai/assistant/constitution/` — global invariants と always-loaded protocols (drift-protocol, communication, thinking, research-first-protocol, ui-definition-protocol, cli-ux-guidelines, test-layers 等)。                                            |
| Manifest layer            | `.qfai/assistant/manifest/` — per-project spine (Kiro 流: product / tech / structure / manifest)。always-loaded、プロジェクト側で fill する。                                                                                                             |
| Catalog layer             | `.qfai/assistant/catalog/` — controlled-vocabulary registries (`agent-catalog.yml`, `agent-routing.yml`, `review-profiles.yml`, `review-gate.rules.yml`, `change-classification.md`, `spec_required_files.json`)。validators / routing から loaded。      |
| Process partition         | `.qfai/assistant/process/` — pipeline / methodology / `migrations/`。stage skills が loaded。                                                                                                                                                             |
| Steering work-log         | `.qfai/steering/` (project-root、`.qfai/assistant/` 配下ではない) — AI 作業ログ surface。per-project、untracked by default、配布物外。entry は frontmatter-typed Markdown。                                                                               |
| work-log entry            | `.qfai/steering/<id>.md` の単一 Markdown ファイル。YAML frontmatter (id / status / kind / created / updated / scope / blocking / promote-to / links) + body。                                                                                             |
| kind (work-log)           | entry が表す出来事の種類。enum: `milestone` \| `decision` \| `risk` \| `consultation-needed` \| `unexpected` \| `unscoped-discovery` \| `handoff` \| `blocker` \| `scope-up` \| `scope-down` \| `spike`。`10_Policy.md` の write-trigger SSOT と 1-to-1。 |
| status (work-log)         | entry のライフサイクル。enum: `active` \| `handoff` \| `archived`。                                                                                                                                                                                       |
| scope (work-log)          | entry の適用範囲。`global` (project-wide) または `spec-NNNN` (per-spec)。                                                                                                                                                                                 |
| promote-to                | `kind: decision` entry を per-spec `07_Decisions.md` の特定 row に昇格させる宛先 path、または `null`。                                                                                                                                                    |
| promoted-to               | `status: archived` 時に promotion が完了したことを記録する back-reference field。                                                                                                                                                                         |
| drift-prevention contract | 全実装/レビュー skill が author 前に open work-log entry を読み、Reviewer Gate が出力との contradiction を `R-WORKLOG-DRIFT` で flag する契約 (REQ-0006)。                                                                                                |
| decision-promotion gate   | `kind: decision` + 非 null `promote-to` の entry を `qfai validate` が `W-PENDING-PROMOTION` で surface し続け、`07_Decisions.md` への row 追加 + entry archive の両条件で gate が閉じる仕組み (REQ-0007)。                                               |
| handoff brief             | `kind: handoff` entry body の 5 セクション構造 (State / Next action / Constraints / OQs / References)。Anthropic handoff pattern (SRC-0016W) に準拠。                                                                                                     |
| R-WORKLOG-DRIFT           | Reviewer Gate finding (severity error, advisory-failing): 新規 implementation 出力が open entry の direction と矛盾する。`justification:` 非空必須。                                                                                                      |
| R-REJECTED-READOPT        | Reviewer Gate finding (severity error, advisory-failing): 出力が active spec の `07_Decisions.md` で `Status: rejected` の option を再採用する。`justification:` 非空必須。                                                                               |
| R-HANDOFF-INCOMPLETE      | Reviewer Gate finding: `kind: handoff` entry body の 5 セクションの何れかが欠落。                                                                                                                                                                         |
| W-PENDING-PROMOTION       | `qfai validate` warning: `kind: decision` + 非 null `promote-to` の entry が promote されていない。                                                                                                                                                       |
| W-WORKLOG-SCHEMA          | `qfai validate` warning: entry frontmatter が schema に違反 (非 blocking)。                                                                                                                                                                               |
| W-WORKLOG-STALE           | `qfai validate` warning: `status: active` entry の `updated` が 90 日超。                                                                                                                                                                                 |
| W-WORKLOG-BROKEN-LINK     | `qfai validate` warning: `links` array の要素が既存 artifact に解決しない。                                                                                                                                                                               |
| D-DEPRECATED-PATH         | `qfai validate` finding: 旧 layout path への参照。deprecation window 中は warning、sunset version 以降は error。                                                                                                                                          |
| W-SKILL-DOC-BROKEN-REF    | `qfai validate` finding: `qfai-*` SKILL.md が現 layout に解決しない assistant path を参照。window 中は warning、sunset 以降は error。                                                                                                                     |
| W-USER-EDIT-PRESERVED     | `qfai init --upgrade-assistant-tree` 時に collision が発生し user-edited file が旧 path に preserve された旨を伝える warning。                                                                                                                            |
| E-WORKLOG-SECRET          | 既存 secret-pattern scan が work-log entry 内に secret 候補を検出した旨の error (hard-block)。                                                                                                                                                            |
| assistantPaths.ts         | `packages/qfai/src/core/paths/assistantPaths.ts` — 配布 assistant file の canonical relative-path を export する SSOT module。hard-coded path string literals は lint で reject される (NFR-0001)。                                                       |
| project_memory block      | `qfai-*` SKILL.md に含まれる YAML block。当該 skill が読む layer を列挙する。`qfai validate` は宣言外の path read を reject する (REQ-0010)。`constitution/` は implicitly always-loaded で列挙不要。                                                     |
