- `resolved` — answered within this change, with the answer recorded in the row itself.
  `OQ-0017-0006` is the only one: its premise (that the ATDD scan reads a repository-root
  directory this repository does not have) was falsified at review round 8, so no placement
  decision and no owner remain.
- `deferred` — decided not to decide now, with a named trigger. All three deferred rows mirror an
  upstream deferral in `discussion-20260804173914356/13_Deferred.md` or a repository-policy
  constraint (OC-3, OC-4, OC-5), and none of them blocks this spec from being implemented.
