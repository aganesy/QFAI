# 07 Decisions

## Purpose

Architectural and behavioral decisions for spec-0017. These are the load-bearing decisions that downstream execution must respect.

## Decision Table

| DEC-ID         | Title                                                 | Decision                                                                                                                                                                                                                                 | Rationale                                                                                                                                                                                 | Status   |
| -------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| DEC-0017-0001  | Mode differences limited to maxCycles                 | Mode differences for `/qfai-prototyping` are strictly limited to `maxCycles` (low-cost=1, standard=3, full-harness=20). No other gate, obligation, reviewer severity, or completion criterion may vary by mode.                          | Historical mode differentiation introduced skew: low-cost runs were shipped with weaker visual review than the repo assumed. Treating mode as "how many cycles you can afford" makes the contract obvious. | Accepted |
| DEC-0017-0002  | Playwright CLI is the sole standard browser tool      | The single supported `browserTool` is `playwright-cli`. Playwright MCP is not a standard path. Node Playwright direct invocation is removed.                                                                                             | 2026 guidance (Playwright `agent-cli` docs, `playwright-mcp` README) favors CLI for coding agents due to token efficiency. QFAI's shell-first runtime aligns with CLI-per-screen semantics. MCP can be reintroduced as a future plugin. | Accepted |
| DEC-0017-0003  | AI evaluator sub-agent performs visual judgment       | QFAI validators MUST NOT compute visual scores. The AI evaluator sub-agent reads screenshots/HTML/snapshots and performs the 6-category scoring.                                                                                         | Aligns with Anthropic "Harness design for long-running application development" — generator/evaluator separation with live-page inspection via Playwright.                                 | Accepted |
| DEC-0017-0004  | Evidence schema moves to PrototypingCycleEvidence     | `FullHarnessIterationEvidence` is removed and replaced with `PrototypingCycleEvidence`. No alias is kept.                                                                                                                                | Name no longer matches reality (no longer "full-harness only"). Breaking rename is cheaper than keeping two parallel names alive.                                                         | Accepted |
| DEC-0017-0005  | QFAI CLI adds `qfai prototyping prepare`              | A prepare command generates review bundle + Playwright CLI command plan without evaluating or capturing evidence.                                                                                                                        | Keeps deterministic artifact generation in QFAI's province; evaluation stays with the AI evaluator sub-agent.                                                                              | Accepted |
| DEC-0017-0006  | Legacy config keys are rejected, not aliased          | `browserProvider` / `renderProvider` cause config load error. No silent migration.                                                                                                                                                       | Silent aliasing would allow stale pipelines to run with new gates, producing confusing errors later. Fail loud at the boundary.                                                            | Accepted |
| DEC-0017-0007  | Lighthouse gate is not required in the unified gate   | Lighthouse becomes optional auxiliary evidence; it is removed from the required completion gate.                                                                                                                                         | Lighthouse does not evaluate the visual-judgment categories the AI evaluator owns. Forcing it across all modes raises cost without proportional safety gain.                               | Accepted |
| DEC-0017-0008  | primaryTasks stay natural-language in command plan    | `interaction` entries in `PlaywrightCliCommandPlan` carry the natural-language task text as `note`; they do not auto-generate click/fill commands.                                                                                       | Auto-translation of NL to CLI click/fill is unreliable. The AI evaluator interprets the note and issues concrete CLI commands during execution.                                            | Accepted |
| DEC-0017-0009  | .qfai/ and packages/qfai/assets/init/.qfai/ stay identical | Skill, references, and templates under `qfai-prototyping` are byte-identical in both trees. `diff -r` is the canonical check.                                                                                                         | Drift between the two trees historically caused "installed qfai differs from source" support issues.                                                                                        | Accepted |
| DEC-0017-0010  | v1.8.3 accepts breaking changes                       | This spec's changes are breaking and justified without a compatibility shim.                                                                                                                                                             | Compatibility shims mask invariant violations. A clean v1.8.3 bump is preferable to a half-migrated v1.8.2 patch.                                                                           | Accepted |
