# 04 Business Rules

## Purpose

- Decompose AC into explicit business rules.
- Every BR must reference one or more AC IDs.

## Rule Table (required)

| BR-ID        | Title                                      | AC-Refs                    | Rule                                                                                                                                                                | Notes                                             | NFR-Refs |
| ------------ | ------------------------------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | -------- |
| BR-0017-0001 | Mode obligations are maxCycles-only-differ | AC-0017-0001, AC-0017-0009 | `derivePrototypingObligations` MUST return identical values across low-cost/standard/full-harness except `maxCycles`. Runtime detection of any other delta MUST emit QFAI-PROT-MODE-001. | Eliminates full-harness-only gates                | NFR-0017 |
| BR-0017-0002 | Playwright CLI is the sole browser tool    | AC-0017-0002               | The config key `prototyping.execution.browserTool` MUST equal `"playwright-cli"`. | BR-0017-0003 | Command plan is deterministic              | AC-0017-0002               | Given the same `(targetUrl, cycle, screen)` triple, `buildPlaywrightCliCommandPlan` MUST return byte-identical command plan structure.                              | Enables fixture-based tests                       | NFR-0019 |
| BR-0017-0004 | QFAI does not score visual quality         | AC-0017-0003               | QFAI validators MUST NOT compute visual scores. | BR-0017-0005 | Evidence refs must be concrete             | AC-0017-0003               | `evaluator-review.json` `scores[].evidenceRefs[]` entries MUST be non-empty strings pointing to existing artifact files.                                            | Placeholders/tbd/empty strings are rejected       | NFR-0018 |
| BR-0017-0006 | Cycle evidence is required for every cycle | AC-0017-0004, AC-0017-0007 | Every `cycles[]` entry in `prototyping.json` MUST reference commandPlan, reviewBundle, evaluatorReview, and per-screen screenshot/html/snapshot/command-log.        | Missing any single ref is error in all modes      | NFR-0018 |
| BR-0017-0007 | Canonical latest paths mirror latest cycle | AC-0017-0004               | Canonical `.qfai/evidence/prototyping/screenshots/<screen-id>.png` and `.../html/<screen-id>.html` MUST match the newest cycle's artifacts for the same screen.     | Kept for backward compat of downstream tools      |          |
| BR-0017-0008 | Prepare CLI does not evaluate              | AC-0017-0005               | `qfai prototyping prepare` MUST produce `review-bundle.json` and `playwright-commands.json` only; it MUST NOT call Playwright, capture evidence, or score.          | Delegation boundary with AI evaluator             |          |

| BR-0017-0011 | Mode-branching in validators is prohibited | AC-0017-0010               | Validator code MUST NOT contain `if (mode !== "full-harness") return []` style early-exit branches. | BR-0017-0012 | No MCP standard path                       | AC-0017-0011               | No asset, template, config key, or skill reference in `packages/qfai` or `.qfai` MUST refer to `playwright-mcp` or MCP templates for prototyping.                   | Future plugin reintroduction is out of scope      | NFR-0020 |
