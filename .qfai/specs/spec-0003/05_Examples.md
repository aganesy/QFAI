## Upgrade-state fixtures (2026-09-24)

The examples from EX-0003-0053 on name these overlays. Each is applied to a tree a fresh
`qfai init` wrote into a temp root whose name contains a space. An overlay name the fixture
factory does not know fails the test.

- `older-plan` — a plan's bytes replaced by a synthetic earlier body, and its lock record
  rewritten to that body's hash: an unmodified install from an earlier release.
- `edited-plan` — a plan's bytes edited, the lock untouched: a user-modified asset.
- `crlf-plan` — an unmodified plan rewritten with CRLF endings: a CRLF checkout.
- `edited-memo` — a memo under `process/migrations/` edited: an edit in an ungoverned path.
- `older-lock` — the lock's package version set to an earlier version.
- `absent-skills` — `qfai-run`, `qfai-maintain`, their wrappers, the plans and their lock
  records removed: an install that predates the workflow entry.
- `absent-route` — the shipped `qfai-maintain` routing entry removed from
  `agent-routing.yml`, the other entries reordered and one agent added.
- `dropped-reviewer` — a blocking reviewer removed from a shipped phase.
- `benign-manifest` — entries reordered and one agent added, with every shipped entry and
  required role kept.
- `older-gitignore` — the managed block replaced by the current block without `.qfai/runs/`
  and `!.qfai/evidence/workflow/`.
