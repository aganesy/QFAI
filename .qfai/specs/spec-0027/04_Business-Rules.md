# 04 Business Rules

## Purpose

- Decompose AC into explicit business rules.
- Every BR must reference one or more AC IDs.

## Rule Table (required)

| BR-ID        | Title                                     | AC-Refs                    | Rule                                                                                                                                               | Notes                                              | NFR-Refs |
| ------------ | ----------------------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | -------- |
| BR-0027-0001 | Pipeline stage order is fixed             | AC-0027-0001               | Pipeline MUST execute stages in order: search→rank→fetch→extract→sanitize→cache→verify→cite. Skipping stages is not allowed.                       | Reproducibility trade-off (Inception Deck Q9)      |          |
| BR-0027-0002 | Pipeline stage failure isolation          | AC-0027-0002, AC-0027-0003 | Each pipeline stage MUST produce a defined output or an explicit failure.
