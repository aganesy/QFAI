## EX-0021-0001: 正常なクリティークループ実行例

**BR Ref:** BR-0021-0002, BR-0021-0003, BR-0021-0005

| Field              | Value                                                                     |
| ------------------ | ------------------------------------------------------------------------- |
| 入力               | 初回レンダリング済み HTML プロトタイプ                                    |
| デスクトップ批評   | PASS — layout 整合、CTA hierarchy 明確、visual anchor 一致               |
| モバイル批評       | REVISE — タッチターゲット 32px（44px 未満）、折り返し時の余白不足         |
| エビデンス記録     | 日時、viewport、判定、指摘事項が記録される                                |
| ループ継続         | モバイル指摘を修正し再批評→両方 PASS で完了                              |
