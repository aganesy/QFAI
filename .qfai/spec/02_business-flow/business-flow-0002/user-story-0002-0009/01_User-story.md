# US-0002-0009: Distributed-surface guards learn the story-tree ID shapes

## User Story

As a QFAI maintainer, I want the pre-build lint, the post-build guard and the smoke test to reject the story-tree internal ID shapes in the shipped surface while admitting an ID numbered in the sample band, as `spec-0001` to `spec-0009` are admitted today, so that no such ID reaches an adopter through a template or a skill.

## Non-goals

- Narrowing an existing pattern
- A pragma or an allow-list entry in a guard
