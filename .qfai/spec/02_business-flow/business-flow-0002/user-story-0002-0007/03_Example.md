# Examples

## Examples

| EX-ID           | AC-Ref          | Input                                                                                                                                                                                   | Expected                                                                                                                                                                                                                                                                                                                                                                                    |

| EX-0002-0007-01 | AC-0002-0007-01 | Inspect the owner-set resolution path, and place `qfai-orphan.yml`, which neither list names, in the adopter tree                                                                       | The write set equals `SHIPPED_WORKFLOW_NAMES` and the prune set equals `RETIRED_WORKFLOW_NAMES`. The two lists share no name. `qfai-orphan.yml` enters neither set and is left untouched, which shows that neither set comes from a prefix glob                                                                                                                                             |
| EX-0002-0007-02 | AC-0002-0007-01 | Read the provenance record in four states: absent, missing `workflows` key, invalid JSON and valid JSON; inspect the managed `.gitignore` block                                         | The first three states read as empty without throwing, so files remain adopter-owned. A valid record returns the bytes QFAI wrote as sha256 with `installedByVersion` and `installedAt`, and no `schemaVersion`. The managed `.gitignore` block re-includes `!.qfai/install-provenance.json`, keeping the record tracked.                                                                   |
| EX-0002-0007-03 | AC-0002-0007-01 | One fixture for each combination of a provenance entry present or absent and a file on disk present or absent, with its bytes matching or not; run init and resolve each state          | The five states resolve to `absent`, `adopter-owned`, `installed`, `modified` and `declined`. A `declined` file is not recreated, not reported stale and not pruned. `absent` is reported apart from `declined`. No prune happens in any of the five states. The two causes of `modified` can be told apart by the record's sha256                                                          |
| EX-0002-0007-04 | AC-0002-0007-01 | Statically inspect the module on the write and removal path, and run the name-collision, declined and `modified` fixtures through it                                                    | The module holds no `copyFile`, `writeFile`, `rm` or `unlink` call of its own. All three fixtures are processed through `copyTemplateTree`, `copyTemplatePaths` or `pruneMatchingEntries`. The create-only `force: false` literal stays at the call site and is not lifted into `options.force`. The collision file and the `modified` file are byte-identical before and after `qfai init` |
| EX-0002-0007-05 | AC-0002-0007-02 | A fixture with one shipped name that provenance records as installed but that is absent from disk (declined); run `qfai init` and observe the set of names passed to the copy primitive | The name is not in the copy set before any copy runs, and it is still absent from disk after init. A control run with the create-only check disabled writes the name out; that control is what can falsify the claim that the exclusion is a mechanism independent of create-only                                                                                                           |
| EX-0002-0007-06 | AC-0002-0007-01 | Inspect whether `pruneMatchingEntries` in `packages/qfai/src/cli/commands/init.ts` is exported, and the predicate of its call for the workflows directory                               | `pruneMatchingEntries` is exported. The predicate of the workflows-directory call is membership in `RETIRED_WORKFLOW_NAMES`, not a prefix predicate. No parallel implementation, such as a separate removal helper, exists                                                                                                                                                                  |
