# US-0002-0021: Layer-to-CI-lane mapping in the layer rule

## User Story

As a contributor deciding which CI lane a test belongs to, I want the layer-to-lane mapping in the shipped `rule/test-layers.md`, adding no layer token or heading and activating no per-level routing, so that I can find it beside the layer taxonomy.

## Non-goals

- A separate mapping file.
- Adding a layer, a layer token or a layer heading.
- Placing annotations outside the validator's test scan.
- Authoring the repository-root link directly.
