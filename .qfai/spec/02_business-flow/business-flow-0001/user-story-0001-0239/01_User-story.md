# US-0001-0239: Answer agent output in the reply form that fits it

## User Story

As an adopter answering an agent, I want each output put to me in the reply form that fits it, choosing, marking up, sorting or comparing, on a page where my host can publish one, so that I correct the output once, at the place it is wrong.

## Non-goals

- A new question, step or gate that waits on me.
- A QFAI command or a shipped page template that builds the pages.
- A page anyone but me can open without my approval, a Site in the Codex app excepted, which the rule itself names as that app's reply-sheet publisher.
