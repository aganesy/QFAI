# US-0001-0214: Close, answer or hand back a request without a change

## User Story

As an operator, I want a request that needs no change to be answered, closed, split or handed back through a route that changes no product file and commits locally only its deliberation record and the `open-questions.md` rows it wrote, so that the interview behind a closure is kept and questions, duplicates and hand-offs end cleanly instead of running a change they do not need.

## Non-goals

- A follow-up request routed inside the route that found it.
- Merging, tagging or publishing anything.
