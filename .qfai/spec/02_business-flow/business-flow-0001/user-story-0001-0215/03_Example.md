# Examples

## Examples

| EX-0001-0215-01 | AC-0001-0215-01 | An orchestrated verify work order for stage instance `verify-1`, and a verify run whose gates pass, when the stage writes `.qfai/report/verify.json` with `status: "PASS"` and `scope: "full"` and returns                                                                                                | Its `artifactRefs` name that `.qfai/report/verify.json` with the digest of the file this stage wrote. The stage runs its own gates, writes its own `.qfai/report/verify.json` and names that file                                                                                                                                                                                                         |
