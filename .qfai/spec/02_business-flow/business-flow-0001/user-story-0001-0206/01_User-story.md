# US-0001-0206: Resolve only the unsettled scope as a stage of a run

## User Story

- Goal: As an operator whose request needs a discussion before it can be
  planned, I want the discussion stage of a run to ask only about what the run
  has not settled, so that I am not asked again what I already answered.
- Non-goals: how the run continues after the discussion stage, which the plan
  decides; grilling inside a run in general; the shared stage-skill rules every
  skill follows.
- Notes: discussion-20260923171450572#REQ-0055, #REQ-0051 and #REQ-0052.
