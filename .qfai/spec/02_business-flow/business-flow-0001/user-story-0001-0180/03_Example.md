# Examples

## Examples

| EX-ID           | AC-Ref          | Input                                                                                                                                                                        | Expected                                                                                                                                                                    |
| --------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EX-0001-0180-01 | AC-0001-0180-01 | A legacy `session-handoff.yaml` with fields not in the canonical schema, and the operator runs `qfai handoff upgrade session-handoff.yaml`                                   | A conforming `handoff.yaml` is emitted at the canonical path with the recognized fields mapped and every original field preserved under a `legacy:` key (no data loss)      |
| EX-0001-0180-02 | AC-0001-0180-01 | An existing `.qfai/handoff.yaml`, and the operator runs `qfai handoff upgrade session-handoff.yaml`, then the same command with `--force`                                    | The first run exits 1 and leaves the existing file unchanged. The second saves the previous contents to a timestamped backup beside it and then writes the upgraded handoff |
| EX-0001-0180-03 | AC-0001-0180-01 | The operator runs `qfai handoff upgrade session-handoff.yaml --dry-run`, once in a project with no canonical handoff and once, with `--force` too, in a project that has one | Each run reports the operation it would perform, or the refusal it would meet, and neither creates nor changes `.qfai/handoff.yaml`                                         |
| EX-0001-0180-04 | AC-0001-0180-01 | The operator runs `qfai handoff upgrade` on a legacy path that does not exist, and on a legacy file holding only whitespace beside an existing `.qfai/handoff.yaml`          | Both runs fail. No canonical handoff is created by the first, and the existing one is unchanged after the second                                                            |
