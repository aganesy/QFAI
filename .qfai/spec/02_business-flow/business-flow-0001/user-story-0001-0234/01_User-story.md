# US-0001-0234: Choose the graph CLI that answers the exploration question

## User Story

As a coding agent, I want to query CodeGraph for code structure and Graphify for document concepts through the managed CLI, so that I obtain relevant evidence without running both engines for every question.

## Non-goals

- A vector store or semantic completeness claim.
- Automatic remote or paid document analysis.
- Graph MCP requests, servers, daemons or IPC.
