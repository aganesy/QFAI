# US-0001-0237: Prepare project-local graph CLIs through init

## User Story

As a project maintainer, I want to prepare project-local CodeGraph and Graphify CLIs when I initialize or upgrade QFAI, so that agents can explore through commands without a global installation or graph MCP connection.

## Non-goals

- Provisioning during npm installation.
- Selecting or invoking a document model during init.
- Registering or launching a graph MCP server.
