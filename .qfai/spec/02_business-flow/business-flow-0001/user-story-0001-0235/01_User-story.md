# US-0001-0235: Steer exploratory searches to the graph CLIs

## User Story

As a project maintainer, I want the shipped rules to name the graph CLIs as the first choice for searching, exploring and investigating, so that agents prefer graph evidence while ordinary search stays available whenever they need it.

## Non-goals

- Blocking, denying or rerouting a direct search with a pre-tool hook.
- Detecting which searches an agent runs.
