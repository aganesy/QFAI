# US-0001-0108: Declared layout anti-pattern review

## User Story

As a reviewer, I want to match each iteration against the identifiers declared in `packages/qfai/assets/validators/layoutAntiPatterns.json`, each carrying the authority that makes it a defect (a published heuristic, an accessibility criterion or the screen contract the screen is built to), and to raise each detection as a blocking finding, so that every layout defect I report rests on a declared authority.
