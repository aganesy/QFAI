# Examples

## Examples

| EX-ID           | AC-Ref          | Input                                                                                                                                                                                                | Expected                                                                                                                                                                         |
| --------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EX-0001-0108-01 | AC-0001-0108-03 | Given the ordinal scale `weak < acceptable < strong < exceptional`. When `ordinalIndex` is applied.                                                                                                  | Then `ordinalIndex(weak) === 0`, `ordinalIndex(acceptable) === 1`, `ordinalIndex(strong) === 2`, `ordinalIndex(exceptional) === 3`. Other inputs are rejected by the type guard. |
| EX-0001-0108-02 | AC-0001-0108-02 | Given iterations 5, 6, and 7 all score information architecture as `acceptable`, and iteration 7 records a layout anti-pattern. When `computePivotDirective` runs.                                   | Then it returns `pivot`.                                                                                                                                                         |
| EX-0001-0108-03 | AC-0001-0108-03 | Given iterations 5, 6, and 7 all score information architecture as `acceptable`, and iteration 7 has no layout anti-pattern and fewer than two improving UX axes. When `computePivotDirective` runs. | Then it returns `refine`.                                                                                                                                                        |
| EX-0001-0108-04 | AC-0001-0108-03 | Given the latest iteration improves at least two of the four UX axes against the prior iteration and does not meet the pivot condition. When `computePivotDirective` runs.                           | Then it returns `continue`.                                                                                                                                                      |
| EX-0001-0108-05 | AC-0001-0108-01 | Given `pivotDirective` is `continue`, `refine`, or `pivot`. When the directive type guard validates it.                                                                                              | Then each value is accepted.                                                                                                                                                     |
| EX-0001-0108-06 | AC-0001-0108-01 | Given `pivotDirective` is `stop` or missing. When the directive type guard validates it.                                                                                                             | Then the value is rejected and a persisted invalid directive raises `QFAI-PROT-002`.                                                                                             |
