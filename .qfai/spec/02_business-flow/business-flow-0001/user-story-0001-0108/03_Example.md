# Examples

## Examples

| EX-ID           | AC-Ref          | Input                                                                                                                                                            | Expected                                                                                                                                                  |
| --------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EX-0001-0108-01 | AC-0001-0108-03 | Given a review whose `informationArchitecture` score is `excellent`. When its scores are validated.                                                              | Then the score is rejected; only `weak`, `acceptable`, `strong` and `exceptional` are accepted.                                                           |
| EX-0001-0108-02 | AC-0001-0108-02 | Given reviews 5, 6 and 7 have `open` counts (blocking findings plus layout anti-patterns) of 2, 2 and 3. When the reviewer writes `pivotDirective` for review 7. | Then it writes `pivot`: the count is above zero and did not fall across the three reviews.                                                                |
| EX-0001-0108-03 | AC-0001-0108-03 | Given reviews 5, 6 and 7 have `open` counts of 3, 1 and 1. When the reviewer writes `pivotDirective` for review 7.                                               | Then it writes `refine`: the count fell from 3 at review 5 to 1 at review 6, so the pivot condition fails, and it did not fall from review 6 to review 7. |
| EX-0001-0108-04 | AC-0001-0108-03 | Given reviews 5, 6 and 7 have `open` counts of 4, 3 and 1. When the reviewer writes `pivotDirective` for review 7.                                               | Then it writes `continue`, because the count fell from 3 to 1.                                                                                            |
| EX-0001-0108-05 | AC-0001-0108-01 | Given `pivotDirective` is `continue`, `refine`, or `pivot`. When the directive type guard validates it.                                                          | Then each value is accepted.                                                                                                                              |
| EX-0001-0108-06 | AC-0001-0108-01 | Given `pivotDirective` is `stop` or missing. When the directive type guard validates it.                                                                         | Then the value is rejected and a persisted invalid directive raises `QFAI-PROT-002`.                                                                      |
