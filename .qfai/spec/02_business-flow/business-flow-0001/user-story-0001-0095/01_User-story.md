# US-0001-0095: Simplified Handoff Schema

## User Story

As an implementation worker, I want to read the prototyping handoff from `.qfai/prototype/final/handoff.json`, a record of the canonical handoff schema, so that I receive the final prototype, the procurement record and the implementation notes without relying on the retired `mustPreserve`/`mayAdapt`/`mustNotCopy` triplets.
