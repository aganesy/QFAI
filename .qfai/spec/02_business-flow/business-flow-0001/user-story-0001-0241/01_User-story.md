# US-0001-0241: Check that discussion-pack citations resolve

## User Story

As a reviewer of a discussion pack, I want validation to report a file and line citation that points at no file or past the file's end, so that every repository fact the pack cites can be opened where it says.

## Non-goals

- Judging whether the cited line supports the claim.
- Checking citations in the story tree, the assistant tree or a report.
