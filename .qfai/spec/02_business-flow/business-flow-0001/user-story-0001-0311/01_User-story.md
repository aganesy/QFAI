# US-0001-0311: Derive the design tokens and the theme from DESIGN.md

## User Story

As an adopter whose brand lives in root `DESIGN.md`, I want `qfai catalog design` to write the tokens as a Design Tokens Community Group file and as the Tailwind 4 theme, and `qfai validate` to warn when either drifts from `DESIGN.md` or UI source holds a hex colour no token states, so that a colour changed in `DESIGN.md` reaches the app through one command and code stops copying values by hand.
