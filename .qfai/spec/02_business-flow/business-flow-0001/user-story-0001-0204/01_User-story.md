# US-0001-0204: Settle one visual decision as a stage of a route

## User Story

As a user whose change needs a visual decision, I want the prototype stage of a route to settle that one decision for the business flow the route is for, within the existing root `DESIGN.md` and UI contracts, so that the work does not stop for a separate `/qfai-prototyping` invocation.

## Non-goals

- When the route reaches the prototype stage, which the plan decides
- The shared stage-skill rules every skill follows
