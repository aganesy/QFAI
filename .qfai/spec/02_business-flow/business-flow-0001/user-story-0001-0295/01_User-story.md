# US-0001-0295: Restyle my running screens without losing their data or what already works

## User Story

As a user restyling screens my product already runs, I want the loop to audit them first, size the change to what the audit finds, edit the visual aspects in a fixed order and keep every figure, name and field value the screens show, so that a restyle improves the look without rewriting my data or rebuilding a screen that was already good.

## Non-goals

- A command or check that decides whether a screen looks generated.
- A change to the data, fields or behaviour a screen shows, which is a contract change.
