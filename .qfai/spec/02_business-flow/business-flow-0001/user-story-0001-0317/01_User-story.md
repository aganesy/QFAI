# US-0001-0317: Hold the story tree and test titles to the glossary's terms

## User Story

As a maintainer whose specification and tests are written with AI agents, I want each glossary term to list the synonyms it rejects and the bounded context it belongs to, and `qfai validate` to report a rejected synonym in the story tree or a test title, so that a term keeps one name everywhere and an agent cannot drift to another word for it.
