# US-0001-0303: Read the grilling rule's procedures only when they apply

## User Story

As a maintainer extending the grilling rule, I want its detailed procedures kept in reference files the rule points to, so that a new clause fits without deleting unrelated wording and an agent reads each procedure only when its case arises.

## Non-goals

- A change to what a grilling session does.
- A lower line ceiling for the rule.
