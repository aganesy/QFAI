# US-0001-0305: Write the standard parts of a business screen into its UI contract

## User Story

As a project lead whose agents build business screens, I want the contract step to add the parts every business screen has, so that navigation, list behaviour, states and feedback reach the UI contract even when no example exercises them.

## Non-goals

- New UI contract keys for states or list behaviour.
- A validate finding for a screen that lacks a part.
