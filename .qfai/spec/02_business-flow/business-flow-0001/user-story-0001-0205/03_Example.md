# Examples

## Examples

| EX-ID           | AC-Ref          | Input                                                                                                                                                                                                                                                                                                                                | Expected                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EX-0001-0205-01 | AC-0001-0205-01 | Given an integration test of `BF-0003` whose one annotation names an AC and which waits a fixed 500 ms instead of waiting for the response, and a diagnosis with verdict `defective-test` whose `matchedIds` name that AC When `/qfai-atdd` serves the `test-fix` work order and replaces the fixed wait with a wait on the response | Then the result's `testFix` names that AC in both `citedBefore` and `citedAfter`, a `reviewRef` from an independent reviewer and a `rerunRef` for the re-run. The fixed test still carries that AC's annotation and no other; its file name or test title may change. No story file, no contract and no `decisions.md` row changes. The re-run is recorded in `.qfai/evidence/atdd-BF-0003.md` |

No result with an accepted `testFix` is returned                                                                                                                                                                                                                                          |
| EX-0001-0205-03 | AC-0001-0205-03 | Given three `defective-test` diagnoses for `BF-0003`, whose `matchedIds` start with the BF ID, with an AC ID and with an EX ID When the `test_fix` stage is assigned                                                                                                                                                                 | Then `/qfai-atdd` serves the work order for the first two.
