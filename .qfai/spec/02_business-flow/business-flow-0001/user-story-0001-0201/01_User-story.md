# US-0001-0201: Diagnose a reported defect without changing product code

## User Story

As an operator reporting a defect against behaviour the tree already states, I want `/qfai-implement` to reproduce it and name its cause without changing any code, so that the session picks the right repair from one verdict.

## Non-goals

- Repairing anything
- Adding the missing example, which `implement-tdd` does in the implement stage
- Choosing the plan branch a verdict leads to
