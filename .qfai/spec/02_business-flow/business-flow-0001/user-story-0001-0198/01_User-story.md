# US-0001-0198: Fix a typo directly

## User Story

As an operator, I want a typo in a comment or in non-normative prose fixed without a story-authoring cycle, so that a trivial fix is quick while a change with any semantic effect still takes the full route.

## Non-goals

- The direct route for a dependency, a workflow, a setting, a normative README command, or QFAI's own skills and rules.
