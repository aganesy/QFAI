# US-0001-0254: Answer the costly decisions of a grilling round first

## User Story

As an adopter answering a grilling round, I want the decisions that are costly to get wrong asked first and the cheap ones grouped so I can accept their recommendations in one answer, so that my attention goes to the decisions that are hard to undo.

## Non-goals

- A change to which round a question belongs to: dependency still decides that.
- An agent accepting a decision on the user's behalf in a user session.
- A change to how a delegated session's rounds are held.
