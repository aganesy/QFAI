# US-0001-0200: Implement as a stage of a run

## User Story

As a user who asked for a feature once, I want `/qfai-implement` to run as a stage of the route and work only the examples of the flow the route is for, so that the work reaches verification without my choosing the flow or typing a stage.

## Non-goals

- Deciding the plan
- Adding an example
- Judging whether the run is complete
