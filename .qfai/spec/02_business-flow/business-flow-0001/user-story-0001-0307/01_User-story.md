# US-0001-0307: Catalogue the components a project already has

## User Story

As an adopter whose agents build screens in parallel, I want `qfai catalog components` to list every component the UI source exports with its source, props, states, pattern and accessibility notes, and `qfai validate` to warn when the list shows a part built twice or bypassed, so that an agent reuses what exists instead of writing the same region again.
