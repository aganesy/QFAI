| EX-0001-0225-08 | AC-0001-0225-03 | The route of EX-0001-0225-07 where `verify-repo-gate` fails                                                    | No commit is made; the work stops and the final report names the failing gate                                                                                                                                                              |
| EX-0001-0225-09 | AC-0001-0225-03 | A `fix-defect` route, from diagnosis to its verify stage                                                       | Before the verify stage only the test being written runs, once failing and once passing; lint, typecheck, build, the full test suite and `qfai validate` each run once, in the verify stage, and no gate runs before the code review       |
