# US-0003-0004: Legacy layout and leftover paths

## User Story

As an operator, I want `qfai doctor` to detect a legacy file layout left over from an older version and list the paths an earlier release wrote that this release no longer uses, so that I know what still needs migrating and what I may delete.

## Non-goals

- Migrating legacy files automatically.
- Deleting a leftover path.
