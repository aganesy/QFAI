# CLI-0013: `qfai prototyping`

## Ownership boundary

This contract decides the prototyping loop behind `/qfai-prototyping`: which UI
contracts a run covers, what cycle 0 freezes, how a review is scored and when
the loop has converged, and what `certify`, `show-ui-contract` and `rescope`
read, write and refuse. It also decides the handoff record the loop leaves in
`prototyping.json`.

The flags, exit codes and per-cycle outputs of `qfai prototyping iterate` are
decided by the `qfai prototyping iterate` contract (CLI-0014). How a stage skill
takes a work order in a run is decided by the `qfai workflow` contract
(CLI-0017).
