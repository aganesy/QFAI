# CLI-0020: Workflow Files

## Ownership boundary

This contract decides the files `npx qfai workflow` writes and reads: the
runtime tree of a run under `.qfai/run/`, the run records under
`.qfai/evidence/workflow/`, the plans the package ships with their format,
vocabulary and load refusals, how a record written under a retired route id is
read, and the JSON Schemas the package ships for the workflow payloads.

`cli-0015-qfai-workflow.md` decides the operations that write these files, the
payload fields, the journal's integrity checks and the rows a run appends to
`decisions.md`. `cli-0002-assistant-steps.md` decides the step tree a plan names
its steps from, and `cli-0009-qfai-init.md` decides the ignore lines that keep
both trees out of git.

| BR-0020-0010 | The plans, one `<route>.yml` for each route the catalog of `cli-0015-qfai-workflow.md` names, are built into the package and are not an extension point: a project does not add, remove or edit one, and QFAI adds no workflow language.
