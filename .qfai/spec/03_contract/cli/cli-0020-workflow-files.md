# CLI-0020: Workflow Files

## Ownership boundary

This contract decides the plans the package ships for `npx qfai workflow
plan`: their format, vocabulary and load refusals, and the JSON Schemas of the
extraction `plan` reads and the document it returns.

`cli-0015-qfai-workflow.md` decides the route catalog the plans implement and
what `plan` returns. `cli-0002-assistant-steps.md` decides the step tree a
plan names its steps from.

| BR-0020-0010 | The plans, one `<route>.yml` for each route the catalog of `cli-0015-qfai-workflow.md` names, are built into the package and are not an extension point: a project does not add, remove or edit one, and QFAI adds no workflow language. `plan` loads them from the installed package's `assets/defaults/workflows/`; `qfai init` installs no copy, and a copy under the project's `.qfai/assistant/` is never read.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | EX-0001-0222-01, EX-0001-0217-02, EX-0001-0196-01                                                                                                       |
| BR-0020-0011 | A plan is a YAML mapping of `route`, equal to the file's base name; `family`, one of `close`, `decide`, `consistency`, `change`, `fix`, `upkeep` and `release`; `stages`, a non-empty list; `decisionPoints`, a list of step names, possibly empty; `releasePoint`, a step name or `end`, absent where the route releases nothing; and `branchPoints`, a list of `{ step, outcomes }`, each outcome `{ outcome, routes }` naming one or more routes, or `decision-table`. | BR-0020-0019 | Two JSON Schemas ship in the package: the extraction `plan` reads and the document it returns. `qfai init` does not copy them into a project, and `qfai-run`'s reference shows each as a JSON example rather than citing a path under `node_modules/`.
