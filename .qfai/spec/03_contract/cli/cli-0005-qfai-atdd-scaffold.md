# CLI-0005: `qfai atdd scaffold`

## Ownership boundary

This contract decides which options `qfai atdd scaffold` accepts, which placeholder test skeletons it writes and where, and how it exits.

What counts as a test at each layer, and the findings `qfai validate` reports while a skeleton still carries its placeholder, are decided by the `qfai validate` contract (CLI-0016). This contract states only how that finding is keyed and when it escalates, because the skeleton carries the placeholder it reads.

## Business rules

| BR-ID        | Statement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Examples                         |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| BR-0005-0001 | `qfai atdd scaffold` takes exactly one of `--story US-NNNN-NNNN` and `--flow BF-NNNN`. Neither, both, a malformed ID, or an ID the story tree does not define exits 2 and writes nothing. `--spec` is not accepted: it exits 2 with a message naming `--story` and `--flow`. Exit 1 is kept for a runtime failure reading or writing a file. `--story` writes one skeleton per AC of the story at `<testsDir>/integration/<US-ID>/<AC-ID>.test.<ext>`, named in the project's test dialect, carrying `QFAI:AC-NNNN-NNNN-NN` and the placeholder `TODO: implement assertion for <AC-ID>`. While that placeholder remains, `qfai validate` reports `D-SCAFFOLD-PLACEHOLDER` at warning, keyed by the AC ID. | EX-0001-0075-01, EX-0001-0075-03 |
| BR-0005-0002 | Re-running `--story` or `--flow` overwrites no existing skeleton, whether filled or still carrying its placeholder, and writes nothing new for an existing target. `D-SCAFFOLD-PLACEHOLDER` escalates from warning to error once the placeholder has stayed through the number of consecutive `qfai validate` cycles `qfai.config.yaml#atdd.scaffoldEscalateCycles` sets, 3 by default, which gives a normal red-to-green turnaround before the placeholder blocks completion. The cycles are counted per AC ID or BF ID; scaffold runs are counted separately.                                                                                                                                           | EX-0001-0075-02, EX-0001-0075-05 |
| BR-0005-0003 | `--flow BF-NNNN` writes one skeleton for the flow at `<testsDir>/e2e/<BF-ID>.test.<ext>`, named in the project's test dialect and carrying `QFAI:BF-NNNN`, and `D-SCAFFOLD-PLACEHOLDER` for it is keyed by the BF ID. An existing file is not overwritten, and a second run writes nothing.                                                                                                                                                                                                                                                                                                                                                                                                               | EX-0001-0075-04                  |
| BR-0005-0004 | When the project's configured test globs select no file name a supported test dialect can write, or would not collect the skeleton's destination as a test, `qfai atdd scaffold` exits 2 before it writes any skeleton.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | EX-0001-0075-06                  |
