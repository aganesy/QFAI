# CLI-0016: Repository CI

## Ownership boundary

This contract holds the rules for this repository's own continuous integration:
the workflows under `.github/workflows/`, the shared setup action, the aggregate
verdict, the workflow hygiene lane, the test runner's projects and parallelism,
and the release gate. Adopters receive none of it.

The workflow templates `qfai init` writes into a consuming project belong to the
shipped-workflows contract. The commands CI runs are listed under Standard
commands in `tech.md`, and the story-tree authoring contract decides where those
commands may be stated.
