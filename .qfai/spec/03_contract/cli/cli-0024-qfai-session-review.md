# CLI-0024: `qfai session-review`

## Ownership boundary

This contract decides which local agent transcripts `qfai session-review` reads, what it counts in them, what its report may hold, where the report goes, and how the command exits.

What the session review does with the report, and when it runs, is decided by the `qfai init` contract (CLI-0009), which owns the shipped session-feedback rule.

## Business rules

| BR-ID | Statement | Examples |
| --- | --- | --- |
| BR-0024-0001 | `qfai session-review` takes `--agent claude\|codex\|all`, `--session <id>`, `--since <date>`, `--format md\|json`, `--out <path>` and `--root`. With no selection it reports the latest session of each chosen agent, `all` by default; `--session` reports the session with that ID, and `--since` every session whose transcript changed at or after that date. The report goes to standard output; `--out` writes it to that file instead, a relative path resolved against the root, and the command writes no other file. Finding no transcript prints one line saying so and exits 0. `--session` with `--since`, a `--since` value that is no date, or a `--session` ID no transcript of the chosen agents holds is a usage error and exits 2. | EX-0001-0240-05, EX-0001-0240-06, EX-0001-0240-07, EX-0001-0240-08 |
| BR-0024-0002 | A Claude Code transcript is `<id>.jsonl` in `projects/<slug>/` under `CLAUDE_CONFIG_DIR`, or under `.claude` in the home directory when that is unset, where the slug is the absolute root with every character other than an ASCII letter or digit replaced by `-`. When that directory holds none, the transcripts of every project directory whose first recorded `cwd` is the root are the project's. A Codex transcript is a `sessions/YYYY/MM/DD/rollout-*.jsonl` file under `CODEX_HOME`, or under `.codex` in the home directory, whose `session_meta` record names the root as its `cwd`, and its session ID is that record's `id`. Paths are compared with forward slashes and no trailing slash, and without regard to letter case on Windows. | EX-0001-0240-01, EX-0001-0240-02, EX-0001-0240-03, EX-0001-0240-04 |
| BR-0024-0003 | A transcript is read line by line from the local disk, with CRLF line ends read as line ends. A line that is not a JSON object is skipped and counted as malformed. The command opens no network connection and imports no network module. | EX-0001-0240-15, EX-0001-0240-17 |
| BR-0024-0004 | Per session the report counts: each QFAI hook reminder shown, keyed by its key in the project's `.agents/rules/reminders.json` when its text is one of that file's texts, else by the words after `QFAI` that name it, and not counting a hook context that does not start with `QFAI`; each file under `.agents/rules/`, `.agents/skills/`, `.qfai/assistant/`, `.claude/rules/` and `.claude/skills/` that a file read or a shell command names, by its repository-relative path, with its reads, its repeats and the bytes of the results that read it alone; each failed tool call, per tool name, with the `QFAI-` finding codes its result carries; each `qfai` command run, by command and subcommand, with the count of each exit status; the structured-question calls and the questions they carry; and the typed user turns. A typed user turn is a message the user wrote, not a tool result, a system or notification wrapper, or an interruption notice. Each typed turn that matches the fixed English and Japanese correction word list is listed by its number among the typed turns and its matched words. | EX-0001-0240-09, EX-0001-0240-10, EX-0001-0240-11, EX-0001-0240-12, EX-0001-0240-13, EX-0001-0240-14 |
| BR-0024-0005 | The report holds counts, repository-relative paths, tool names, finding codes, command names and matched words, and no message text, snippet or tool output. Every string it emits passes a fixed redaction set covering GitHub, OpenAI-style and AWS access keys, Slack tokens, JSON Web Tokens, bearer tokens, PEM private keys, `password=` values and e-mail addresses, and the project root and the home directory are written as `<root>` and `~`. | EX-0001-0240-16 |
| BR-0024-0006 | The report lists sessions by agent and then by session ID, and each list inside a session in a fixed order, and carries no wall-clock time, so the same transcripts give byte-identical reports whatever order the file system lists them in. Each session is headed `<agent>-<session ID>`. | EX-0001-0240-08, EX-0001-0240-18 |
