# CLI-0009: `qfai init`

## Ownership boundary

This contract holds the rules for `qfai init`: what it writes into a consuming
project on a fresh install, an upgrade and a forced run, what it leaves alone,
how it edits files the project already has, and the exit code it returns. It
also states the configuration keys a project uses to override the routing and
review-profile defaults.

The ownership boundary of the shipped GitHub Actions workflows belongs to the
shipped-workflows contract. The
workflow command and the files it reads belong to the workflow and
workflow-files contracts, the steps belong to the assistant-steps contract,
how routing selects agents belongs to the assistant-routing contract, and
reporting drift on an installed workflow belongs to the doctor contract.
