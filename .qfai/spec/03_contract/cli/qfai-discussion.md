# CLI Contract: `qfai discussion`

- Contract scope: the discussion command and its active-pack pointer
- Owning specs: `spec-0002` and `spec-0010`
- Used-by: `/qfai-discussion` and `/qfai-sdd`
- SSOT modules: `packages/qfai/src/cli/commands/discussion.ts` and `packages/qfai/src/core/state.ts`

## Command surface

`qfai discussion list` enumerates packs under the configured discussion
directory. `list --active` reads the active pointer from
`.qfai/state.json#discussion.currentId`; it never infers the pointer from
directory modification time. `qfai discussion use <id>` sets that pointer
only after the ID resolves to one existing pack. Text and JSON are supported
for the list view.

A missing, duplicate, or unreadable candidate is reported with the available
pack names and a recovery command. A malformed configuration must not make
the command silently inspect a default directory in place of the configured
one. An absent discussion directory is an empty pack set. The discussion
skill owns pack authoring; this contract owns the command and pointer.
