# CLI-0018: Shipped GitHub Actions workflow set

## Ownership boundary

This contract decides which workflow files QFAI ships into an adopter's `.github/workflows/`, which files in that directory QFAI may write, that it keeps no record of them and removes none, and the structural shape the shape gate holds the shipped set to.

When `qfai init` runs, and what else it writes, are decided by the `qfai init` contract (CLI-0009). QFAI's own CI is decided by the repository CI contract (CLI-0016).

This is a contract of its own, rather than a section of the init contract, because a later refresh command would read it too. No command refreshes the set yet.
