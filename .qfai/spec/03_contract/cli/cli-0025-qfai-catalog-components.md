# CLI-0025: `qfai catalog components`

## Ownership boundary

This contract decides which files `qfai catalog components` reads, what it counts as a component, which fields it records, the file it writes, its `--check` mode and how it exits. It also decides what the shipped implementation guidance tells an agent about the catalogue.

The warnings `qfai validate` raises from the committed catalogue belong to the `qfai validate` contract (CLI-0014). Where a screen region comes from belongs to the shipped procurement rule.

## Business rules

| BR-ID | Statement | Examples |
| --- | --- | --- |
| BR-0025-0001 | `qfai catalog components` takes `--check` and `--root`. It reads the `.tsx` and `.jsx` files the `uiux.surfacePaths` globs select from the root, except under `node_modules` and except a file whose name holds `.test.`, `.spec.` or `.stories.`, with the `typescript` package resolved from the project root. A component is a top-level `function` or `const` whose name starts with an upper-case letter, whose function, or the first function a wrapping call such as `memo(...)` or `forwardRef(...)` receives, holds a JSX element or fragment, and that is exported on its declaration, by name in an `export { ... }` list with no module specifier, or by `export default` of its name. A class component is not listed. | EX-0001-0307-01, EX-0001-0307-02, EX-0001-0307-03, EX-0001-0307-13 |
| BR-0025-0002 | Each component records `name`, its repository-relative `file` with forward slashes, and `props`, taken from the first of these that resolves: the member names, in declaration order, of the first parameter's type when it is a literal, an interface or type alias the same file declares, with the members of the same-file interfaces an interface extends, or an intersection of those; the names an object destructuring of the first parameter binds, rest element aside; the members of the first type argument of the `const`'s own annotation; the members of the last type argument of the outermost wrapping call that has type arguments. A props type nothing in the file declares gives no `props` key. The last `/** ... */` block before the declaration, `//` line comments after it aside, supplies `source`, `reason`, `states` (split on `,`), `pattern` and `a11y` from the tags `@source`, `@reason`, `@states`, `@pattern` and `@a11y`. A line opening with one of these tags and then a space or its end starts that tag; a line opening with another `@word` and then a space or its end ends it; any other line continues the current tag, its lines joined by single spaces. An empty tag gives no key. | EX-0001-0307-01, EX-0001-0307-02, EX-0001-0307-13, EX-0001-0307-14 |
| BR-0025-0003 | The command writes `.qfai/catalog/components.yaml`: two header comment lines, then `components:` as a list sorted by `file` and then by `name`, each entry's keys in the order `name`, `file`, `props`, `source`, `reason`, `states`, `pattern`, `a11y`, with no timestamp, so the same source gives the same bytes. It prints one line naming the file and the number of components, with the number of files and the number with no `@source`, or saying that `uiux.surfacePaths` selects no `.tsx` or `.jsx` file, and exits 0. A read or write failure exits 1. | EX-0001-0307-04, EX-0001-0307-17 |
| BR-0025-0004 | With `--check` the command writes nothing. It exits 0 when the committed file holds the text it would write, CRLF line ends read as LF, and otherwise exits 1 with one line naming the file and saying it does not exist or is out of date, with the command to run. | EX-0001-0307-05 |
| BR-0025-0005 | When a `.tsx` or `.jsx` file is selected and `typescript` cannot be resolved, fails to load, or offers no `createSourceFile`, the command prints one line naming `typescript` and the number of files it could not read, writes nothing, and exits 1. | EX-0001-0307-06 |
| BR-0025-0006 | The shipped implementation UI guidance tells the implementer to read `.qfai/catalog/components.yaml` before writing a region, to reuse a listed component that realises it, and, on authoring a shared component, to write its doc comment with the five tags and run `qfai catalog components`. The procurement ladder's reuse rung and the test-first implementation step point to that guidance. | EX-0001-0307-12 |
