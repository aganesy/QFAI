# CLI-0010: `/qfai-migration-v1-to-v2` scripts

## Ownership boundary

This contract decides the scripts bundled with the `/qfai-migration-v1-to-v2` skill, which move a project from the QFAI 1.x spec packs to the 2.x story-based `.qfai/spec/` tree and then install and check the free-text entry: how each step is invoked, what it reads and may write, what it reports, and how it exits.

Shipping the skill and linking it into the host directories, the managed `.gitignore` block, the entry directive and the reminder hooks are decided by the `qfai init` contract (CLI-0009). The checks `npx qfai workflow start` makes are decided by the `qfai workflow` contract (CLI-0015), and the findings `qfai validate` reports on the migrated tree by the `qfai validate` contract (CLI-0014). How the story tree changes once migrated is decided by the story-tree authoring contract (CLI-0019).
