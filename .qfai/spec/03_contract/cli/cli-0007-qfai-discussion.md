# CLI-0007: `qfai discussion`

## Ownership boundary

This contract decides the `qfai discussion` command, the active-pack pointer it reads and writes, and what a discussion pack written by `/qfai-discussion` holds and when it is complete.

Whether the story-tree stage may start from an incomplete pack is decided by the story-tree authoring contract (CLI-0021). The work order a workflow run hands the skill, and the entry check a stage skill makes under it, are decided by the `qfai workflow` contract (CLI-0017).
