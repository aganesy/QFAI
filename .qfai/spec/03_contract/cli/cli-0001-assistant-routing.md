# CLI-0001: Assistant Routing

## Ownership boundary

This contract decides how QFAI's assistant work is routed and reviewed: the
agent cards as the only agent definition, the routing and review-profile
defaults the package ships and the project overrides that replace them, the
orchestrator's delegation and hard stop, the reviewers each profile requires,
the Default Autopilot Policy of every skill, the handoff schema shared across
skills, and the Reviewer Gate findings that guard those surfaces.

`cli-0002-assistant-steps.md` decides the step tree the routing entries are
keyed by. `cli-0016-qfai-validate.md` decides the machine findings for a
missing card or a broken route, `cli-0011-qfai-init.md` decides the shipped
assistant tree and its host links, and `cli-0017-qfai-workflow.md` decides the
work orders and authorizations of a workflow run. The decision-record command
decides its own query surface.
