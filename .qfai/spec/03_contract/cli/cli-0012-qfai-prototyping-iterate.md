# CLI-0012: `qfai prototyping iterate`

## Ownership boundary

This contract decides `qfai prototyping iterate`: the flags it takes, the cycle
range, the cycle-0 reset and its backups, the opt-in capture and serve paths,
the license patch, what one cycle writes and how the command exits.

What cycle 0 freezes, how a review is scored, when the loop has converged and
what the other `qfai prototyping` sub-commands do are decided by the `qfai
prototyping` contract (CLI-0011).
