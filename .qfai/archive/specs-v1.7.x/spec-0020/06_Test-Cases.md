## TC-0020-0001: Mermaid 遷移図の構文妥当性検証

**Level:** unit
**EX Refs:** EX-0020-0001
**AC Refs:** AC-0020-0001

Setup: UI-bearing spec 内に Mermaid コードブロック（flowchart / sequenceDiagram）が存在する。
Action: Mermaid パーサーで各コードブロックをパースする。
Verify:

- 全コードブロックが構文エラーなくパースできる
- flowchart または sequenceDiagram の宣言が先頭に存在する

## TC-0020-0002: 全画面ノードの到達可能性検証

**Level:** integration
**EX Refs:** EX-0020-0002
**AC Refs:** AC-0020-0002

Setup: Mermaid 遷移図からノードとエッジの一覧を抽出する。
Action: エントリーポイントから BFS / DFS で到達可能性を解析する。
Verify:

- 全ノードがエントリーポイントから到達可能
- 孤立ノード（入辺 0 かつ初期画面でない）が 0 件

## TC-0020-0003: エッジラベル（CTA／イベント名）の存在検証

**Level:** unit
**EX Refs:** EX-0020-0004
**AC Refs:** AC-0020-0003

Setup: 遷移図の全エッジを抽出する。
Action: 各エッジにラベル（テキスト）が付与されているか確認する。
Verify:

- ラベルなしエッジが 0 件
- 各ラベルが空文字列でない

## TC-0020-0004: エラーノードのリカバリーパス存在検証

**Level:** integration
**EX Refs:** EX-0020-0003
**AC Refs:** AC-0020-0004

Setup: 遷移図からエラー状態を表すノードを識別する（命名規則またはスタイルクラスで判定）。
Action: 各エラーノードの出辺を確認する。
Verify:

- 全エラーノードに少なくとも 1 つの出辺が存在する
- 出辺の先が正常フローのノードである

## TC-0020-0005: 行き止まりノード不在検証

**Level:** unit
**EX Refs:** EX-0020-0003
**AC Refs:** AC-0020-0005

Setup: 遷移図の全ノードを抽出する。
Action: 各ノードの出辺数を確認する。明示的終了ノードを除外する。
Verify:

- 明示的終了ノード以外で出辺 0 のノードが 0 件

## TC-0020-0006: デスクトップ／モバイル遷移差分記録の検証

**Level:** integration
**EX Refs:** EX-0020-0005
**AC Refs:** AC-0020-0006

Setup: ビューポート差分が存在するナビゲーション定義を用意する。
Action: 遷移図内にデスクトップ／モバイルの差分記録（サブグラフまたは注釈）が存在するか確認する。
Verify:

- 差分がある場合: desktop / mobile のサブグラフまたは注釈が存在する
- 差分がない場合: 「共通」の明記がある
- 各ビューポートで全画面への到達可能性が維持されている

## TC-0020-0007: 遷移図と UI 実装の整合性チェック

**Level:** integration
**EX Refs:** EX-0020-0006
**AC Refs:** AC-0020-0007

Setup: Mermaid 遷移図と対応する UI 実装（ルート定義、画面コンポーネント一覧）を用意する。
Action: 遷移図のノード名を UI 実装の画面一覧と突合する。
Verify:

- 遷移図の全ノードが UI 実装に存在する
- UI 実装の全画面が遷移図に記載されている

## TC-0020-0008: 遷移図未更新時の不整合検出

**Level:** integration
**EX Refs:** EX-0020-0006
**AC Refs:** AC-0020-0008

Setup: UI 実装に新画面が追加されているが遷移図が更新されていない状態を用意する。
Action: 整合性チェックを実行する。
Verify:

- 不整合として検出される
- レビュー対象として報告される
- review gate を通過しない
