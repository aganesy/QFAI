## EX-0020-0001: 正常遷移フロー（Mermaid flowchart）

**BR Ref:** BR-0020-0001, BR-0020-0003

| Field  | Value                                                                                                                  |
| ------ | ---------------------------------------------------------------------------------------------------------------------- |
| Input  | 3 画面構成（ログイン → ダッシュボード → 設定）の UI spec                                                               |
| State  | Mermaid flowchart を作成                                                                                               |
| Output | `flowchart TD` 形式の遷移図。各エッジに CTA ラベル（例: `--"ログインボタン"-->`, `--"設定リンク"-->`）が付与されている |

## EX-0020-0002: 孤立画面の検出（負例）

**BR Ref:** BR-0020-0002

| Field  | Value                                                                                  |
| ------ | -------------------------------------------------------------------------------------- |
| Input  | 遷移図に「ヘルプ画面」ノードが存在するが、他のどのノードからもエッジが接続されていない |
| State  | 到達可能性チェックを実行                                                               |
| Output | 「ヘルプ画面」が孤立ノードとして検出される。review gate FAIL。遷移図にエッジ追加が必要 |

## EX-0020-0003: エラーリカバリーフロー

**BR Ref:** BR-0020-0004, BR-0020-0005

| Field  | Value                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------- |
| Input  | フォーム送信でバリデーションエラーが発生するシナリオ                                              |
| State  | エラーノードに 2 つのリカバリーパスを定義: (1) 入力修正して再送信、(2) キャンセルして前画面へ戻る |
| Output | エラーノードから正常フローへの復帰パスが 2 本存在。行き止まりなし                                 |

## EX-0020-0004: ラベルなしエッジの拒否（負例）

**BR Ref:** BR-0020-0003

| Field  | Value                                                                                      |
| ------ | ------------------------------------------------------------------------------------------ |
| Input  | 遷移図内のエッジ `A --> B` にラベルが付与されていない                                      |

| Output | ラベルなしエッジとして検出。review gate FAIL。CTA 名称またはトリガーイベント名の付与が必要 |

## EX-0020-0005: デスクトップ／モバイル遷移差分の記録

**BR Ref:** BR-0020-0006

| Field  | Value                                                                                                                                               |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Input  | デスクトップではサイドバーナビゲーション、モバイルではハンバーガーメニュー＋ドロワーで同一遷移先に到達する設計                                      |
| State  | サブグラフで desktop / mobile の差分を明記                                                                                                          |
| Output | 遷移図内に `subgraph Desktop` と `subgraph Mobile` が存在し、両方で全画面への到達可能性が維持されている。ナビゲーション要素名の差分が注釈で記録済み |

## EX-0020-0006: 遷移図と UI 実装の不整合検出

**BR Ref:** BR-0020-0007

| Field  | Value                                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------------ |
| Input  | UI 実装に「通知設定画面」が追加されたが、遷移図が更新されていない PR                                   |
| State  | 整合性チェックを実行                                                                                   |
| Output | 不整合として検出。PR の review gate FAIL。遷移図に「通知設定画面」ノードと関連エッジの追加が要求される |

| Field  | Value                                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
