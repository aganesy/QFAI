# 03 Acceptance Criteria

8 items.

## AC-0020-0001: Mermaid 遷移図の存在と構文妥当性

**US Ref:** US-0020-0001

```gherkin
Given UI-bearing spec が存在する
When ナビゲーションフロー定義を確認する
Then Mermaid 形式（flowchart または sequenceDiagram）の遷移図が 1 つ以上存在する
And 各遷移図が Mermaid パーサーで構文エラーなくレンダリングできる
```

## AC-0020-0002: 全画面の到達可能性

**US Ref:** US-0020-0001

```gherkin
Given Mermaid 遷移図が定義されている
When 遷移グラフを解析する
Then 全ての画面ノードがエントリーポイントから到達可能である
And 孤立ノード（入辺なし＆初期画面でない）が 0 件である
```

## AC-0020-0003: CTA とナビゲーションパスの対応

**US Ref:** US-0020-0001

```gherkin
Given 遷移図内の各エッジ（矢印）
When エッジのラベルを確認する
Then CTA 名称またはトリガーイベント名が記載されている
And DDP で定義された CTA 階層（primary / secondary / tertiary）との整合性がある
```

## AC-0020-0004: エラーリカバリーパスの存在

**US Ref:** US-0020-0002

```gherkin
Given エラー状態を表すノードが遷移図に存在する
When エラーノードからの出辺を確認する
Then 少なくとも 1 つのリカバリーパス（戻り先・再試行・フォールバック）が定義されている
And リカバリー先のノードが正常フローのノードである
```

## AC-0020-0005: エラーフローの行き止まり禁止

**US Ref:** US-0020-0002

```gherkin
Given 遷移図内の全ノード
When 各ノードの出辺を確認する
Then 明示的な終了ノード以外に出辺が 0 のノードが存在しない
And エラー状態から正常フローへの復帰パスが必ず存在する
```

## AC-0020-0006: デスクトップ／モバイル両対応の遷移記録

**US Ref:** US-0020-0001

```gherkin
Given ナビゲーションフロー定義が存在する
When ビューポート別の遷移差分を確認する
Then デスクトップとモバイルで遷移パスが異なる場合、その差分が明記されている
And 各ビューポートで全画面への到達可能性が維持されている
```

## AC-0020-0007: 遷移図と UI 実装の整合性チェック

**US Ref:** US-0020-0003

```gherkin
Given Mermaid 遷移図と対応する UI 実装が存在する
When 遷移図のノード・エッジを UI 実装と突合する
Then 遷移図上の全画面が UI 実装に存在する
And 遷移図上の全遷移パスが UI 上で実行可能である
```

## AC-0020-0008: 遷移図と UI 実装の不整合検出

**US Ref:** US-0020-0003

```gherkin
Given 遷移図に存在しない画面が UI 実装に追加された場合
When 整合性チェックを実行する
Then 不整合として検出され、レビュー対象として報告される
And 遷移図の更新が完了するまで review gate を通過しない
```
