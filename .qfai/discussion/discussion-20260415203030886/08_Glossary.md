# 08 Glossary

| Term | Definition |
|---|---|
| **CalibrationPack** | A resolved calibration pack object loaded by `CalibrationLoader` from a YAML file at `packPath`. Contains the `pack.measurement` data that `runFullHarness()` reads to configure quality gate thresholds. Distinct from `calibrationRef` (the metadata that identifies the pack). |
| **calibrationRef** | A metadata struct identifying the calibration pack used during execution. Fields: `packPath` (path to the pack YAML file), `packVersion` (version string from the pack), and optionally `configPath` (path to a config overlay). Used in summaries and by the validator for authenticity comparison. |
| **concrete artifact ref** | A string that resolves to a specific file, section anchor, or JSON pointer in the evidence or spec corpus. Examples: `40_screen_contracts.md#screen-login`, `screenshots/iter-0-screen-login.png`, `browser-qa/phase-2-findings.json#/finding-3`. Directory paths, self-refs, synthetic tokens, and extension-less strings are NOT concrete artifact refs. |
| **fail-closed** | An execution policy where any incomplete or invalid precondition causes an immediate failure rather than continuing with partial or degraded state. In this context: if `uiFidelity` is not `completed`, execution fails immediately (does not proceed to `runFullHarness()`). |
| **pack SSOT** | Single source of truth for calibration data. The `calibrationPack` object (loaded from `packPath`) is the authoritative source for all threshold and measurement configuration. No scalar overrides in config or CLI are permitted. |
| **specCoverage** | A summary structure (`SpecCoverageSummary`) that records which spec items are covered, and by which evidence refs. The `evidenceRefs` field must contain only concrete artifact refs (after WS-3). |
| **uiFidelity** | A summary structure (`UiFidelitySummary`) that records the completeness of UI evidence (render, screenshot, browser QA) per screen. Only `status = "completed"` with `missingRequiredEvidence = []` and all required screens present is a valid execution-continuing state. |
| **error taxonomy** | The set of 6 distinct error classes defined in `prototyping/errors.ts`, each covering a specific failure domain in the prototyping execution pipeline: `CalibrationResolutionError`, `UiFidelityEvidenceError`, `SpecCoverageBuildError`, `L2EvidenceBuildError`, `FullHarnessRuntimeError`, `EvidenceWriteError`. |
| **isConcreteArtifactRef** | A helper function (exported from `prototypingEvidence.ts`) that returns `true` if a string is a concrete artifact ref, `false` otherwise. Used to validate `specCoverage.evidenceRefs` and `runtimeGate.evidenceRefs`. |
| **FullHarnessRequest** | The request object passed to `runFullHarness()`. After WS-1, it includes `calibrationPack: CalibrationPack` (resolved object) and `calibrationRef: { packPath, packVersion, configPath? }`. It no longer includes scalar threshold parameters or `packPath` as the sole calibration input. |
| **obsolete scalar calibration fields** | Config fields that were previously used to set calibration thresholds directly (`thresholds.accept`, `thresholds.refine`, `maxIterations`, `plateauDelta`, `plateauLookback`). Removed in WS-6; their presence in user config input now causes a normalize-time error. |
| **PROTOTYPING_SUPPORTED_SURFACES** | A constant array in `surfacePolicy.ts` listing the UI surfaces that the prototyping subsystem supports: `["web", "mobile", "desktop", "mixed"]`. Used as SSOT for surface validation and for generating the rejection error message. |
