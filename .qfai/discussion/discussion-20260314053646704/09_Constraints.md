# 09 Constraints

## 技術的制約

| ID | 制約 | 根拠 | 影響 |
| -- | ---- | ---- | ---- |
| TC-001 | TypeScript コードを変更しない | v1.5.5 タイムライン制約、SRC-0001 の即時要求 | 変更はマークダウンファイルのみ |
| TC-002 | AskUserQuestion は VS Code Copilot Chat 環境に依存する | ツール実装が Copilot Chat 側にある | 非対応環境でのフォールバック定義が必須 |
| TC-003 | constitution.md の Article I〜IX の内容を変更しない | 後方互換性の維持（NFR-0004） | Article X の追記のみ |
| TC-004 | 文言変更は SKILL.md の該当セクションのみ | ドリフトプロトコル準拠（他セクション影響禁止） | 変更範囲を明示した上で改訂する |
| TC-005 | `qfai validate --fail-on error` が通ること | 品質ゲートの維持（NFR-0006） | 変更後にバリデーション実行が必要 |

## 運用上の制約

| ID | 制約 | 根拠 | 影響 |
| -- | ---- | ---- | ---- |
| OC-001 | 全 9 SKILL.md を同時に改訂する | 部分適用による不整合を防ぐ | 一括変更が必要（逐次でも可だが完了は一括） |
| OC-002 | フォールバック手順は全スキルで統一する | 一貫性の維持（NFR-0002） | テンプレート文言を先に決定してから各ファイルに展開 |

| OC-004 | `_policies/10_delta.md` は append-only で更新する | 変更履歴の改竄防止 | 既存エントリを編集しない |
