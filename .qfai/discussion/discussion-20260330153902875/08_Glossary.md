# 08_Glossary

| Term | Definition |
| --- | --- |
| convergence release | 既存設計に repo/skills/docs を収束させる修正リリース |
| canonical v1.7 model | discussion, template, validator, prototyping, docs が共有する最終仕様モデル |
| UI-bearing | web-ui / mobile-ui / desktop-ui / mixed surface を持つ project |
| non-ui | CLI, API, library など GUI を持たない surface |
| taste interview | UI-bearing discussion で visual preference / anti-preference を artifact 化する工程 |
| trend scan | 最新 reference を取り込み、adopted/rejected/local translation を明示する工程 |
| 3-layer rubric | invariant / trend-derived / product-specific で評価軸を構成する model |
| aggregate scoring | 3-layer rubric を total score / threshold / plateau rule にまとめる artifact |
| static-first | runtime evidence が常時必須ではなく、静的 deliverable を先に成立条件に置く方針 |
| full-harness | premium かつ explicit に選ぶ高コスト prototyping/evaluation path |
| fail-open | capability が不足しても fake success にせず skip/fail reason を返して継続可能にする動作 |
| semantic review | taste/trend/anchor/contracts の適切性を reviewer が判断する review |
