# 09_Constraints

| ID | Type | Constraint |
| --- | --- | --- |
| C-01 | Repository | 修正対象は `packages/qfai/` であり `.qfai/` の運用成果物は恒久修正対象にしない |
| C-02 | Workflow | discussion stage では implementation-level details を確定しない |
| C-03 | Validation | review cycle ごとに validate 実行結果を残す |
| C-04 | Compatibility | 既存 pack への影響を考慮し staged rollout を前提にする |
| C-05 | Scope | 今回の discussion pack 自体は non-ui として扱い、`prototyping.yaml` は生成しない |
