# 07_NFR

## 非機能要件

| NFR-ID   | カテゴリ | タイトル               | 説明                                                                                | 測定基準                                       |
| -------- | -------- | ---------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------- |
| NFR-0001 | 一貫性   | スキル間の表現統一     | 全 9 スキルで同一の3行パターン構造を使用し、スキル固有部分のみ変更する              | 全セクションのテンプレート構造が同一であること |
| NFR-0002 | 保守性   | 最小限の差分           | 既存スキル構造を壊さず、セクション追加のみで実現する                                | 各スキルの追加行数が 6〜8 行に収まること       |
| NFR-0003 | 互換性   | validator との整合     | 追加セクションが既存の `qfai validate` チェックを壊さない                           | `qfai validate --fail-on error` がパスすること |
| NFR-0004 | 可読性   | エージェント向け明瞭性 | AI エージェントが SKILL.md を読んだ際に、質問方法ルールを即座に理解・適用できること | セクション名とバレットの明確さ                 |
