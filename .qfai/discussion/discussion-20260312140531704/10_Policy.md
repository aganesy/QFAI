# 10_Policy

## ポリシー

| ID      | ポリシー名           | 内容                                                                                                                  |
| ------- | -------------------- | --------------------------------------------------------------------------------------------------------------------- |
| POL-001 | AskUserQuestion 優先 | ユーザーへの質問はすべて AskUserQuestion 機能を優先的に使用する。利用不可の場合のみ通常メッセージにフォールバックする |
| POL-002 | 構造化選択肢         | AskUserQuestion 使用時は、可能な限り番号付き選択肢または YES/NO 形式で質問を構造化する                                |
| POL-003 | パターン統一         | 全 9 スキルで同一の 3 行パターン構造を適用し、スキル固有の例示のみを差分とする                                        |
| POL-004 | 配置位置固定         | 新セクションは `[DRIFT-PROTOCOL:MANDATORY]` 直後に配置し、FORMAT SSOT または Deprecation Notice の前に置く            |
| POL-005 | 最小変更原則         | 既存のスキル構造・ロジックを変更せず、セクション追加のみで対応する                                                    |
