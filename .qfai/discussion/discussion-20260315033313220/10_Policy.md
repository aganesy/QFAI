# 10_Policy

## ポリシー

### セキュリティポリシー

- 該当なし（新エージェントはプロンプト指示のみで動作し、外部アクセスやデータ永続化を行わない）

### コンプライアンスポリシー

- 該当なし（内部開発ツールのため）

### 品質ポリシー

| ID     | ポリシー                                           | 根拠                                                                 |
| ------ | -------------------------------------------------- | -------------------------------------------------------------------- |
| POL-01 | 全否定エージェントは具体的代替案を必ず提示する      | 単なる否定ではなく建設的な改善提案とするため                           |
| POL-02 | パターン倍増エージェントは追加パターンの根拠を示す  | 水増しではなく品質向上に寄与するパターンであることを保証するため       |
| POL-03 | 無限ループ防止策を必ず実装する                       | 全否定の性質上、修正してもFAILが出続ける可能性があるため              |
| POL-04 | 既存10レビュアーの動作に影響を与えない              | 後方互換性の維持                                                     |
| POL-05 | 両エージェントのレビュー結果はRCPに完全記録する      | 可観測性と再現性の担保                                               |
| POL-08 | 全レビュアーはFAIL時に具体的な代替案・修正案を提示する | 単なる否定ではなく建設的な改善提案を義務化しフィードバック品質を担保するため |

### ガバナンスポリシー

| ID     | ポリシー                                           | 根拠                                                                 |
| ------ | -------------------------------------------------- | -------------------------------------------------------------------- |
| POL-06 | 新エージェントのFAIL判定基準はSKILL.mdに明文化する  | 判定の透明性と予測可能性                                             |
| POL-07 | 無限ループ検知時は自動でレビューを打ち切り、OQに登録する | デッドロック防止とエスカレーション経路の確保                         |
