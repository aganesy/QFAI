# 09_Constraints

## 技術的制約

| ID      | 制約                                                                                | 影響                                           |
| ------- | ----------------------------------------------------------------------------------- | ---------------------------------------------- |
| CON-T01 | `qfai init` の配置ロジックは `syncIntegrationWrappers` 内または同等の関数で実装する | init.ts の既存アーキテクチャに従う             |
| CON-T02 | テンプレートアセットは `packages/qfai/assets/init/` 配下に配置する                  | 既存のアセット管理パターンに従う               |
| CON-T03 | `mkdir` は `{ recursive: true }` で呼び出す                                         | `.github/` が存在しない環境でも動作保証        |
| CON-T04 | instructions ファイルは正規ファイル（symlink ではない）として配置する               | ユーザーが直接編集・カスタマイズすることを想定 |

## 運用制約

| ID      | 制約                                    | 影響                               |
| ------- | --------------------------------------- | ---------------------------------- |
| CON-O01 | instructions は create-only、force 無効 | specs/contracts と同等の保護レベル |
| CON-O02 | 配布する instructions は言語非依存      | 特定言語に依存する記述を含めない   |

## 法的・予算・期限

| ID      | 制約                    | 影響                               |
| ------- | ----------------------- | ---------------------------------- |
| CON-L01 | v1.6.3 リリースに含める | 開発範囲を instructions 配置に限定 |
