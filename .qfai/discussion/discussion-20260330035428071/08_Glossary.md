# 08_Glossary

## Terms

| Term                           | Definition                                                                                                                                                                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Canonical Architecture         | 本セッションで最終合意した QFAI の設計モデル。3-layer evaluation、design taste interview、static-first prototyping 等を含む                                                                                                                 |
| Correction-and-Convergence     | 新思想を追加せず、既に確定した仕様へ repo を収束させるリリースタイプ                                                                                                                                                                        |
| 3-Layer Evaluation Model       | invariant / trend-derived / product-specific の3層で構成される評価軸モデル。4-axis model を置換する                                                                                                                                         |
| 4-Axis Model (Legacy)          | usability / consistency / accessibility / delight の固定4軸。v1.7.8 で legacy/deprecated に降格                                                                                                                                             |
| Invariant Axes                 | プロジェクトによらず常に適用される基底評価軸（例: accessibility basics, semantic correctness）                                                                                                                                              |
| Trend-Derived Axes             | live trend research から動的に生成される評価軸。freshness metadata を持つ                                                                                                                                                                   |
| Product-Specific Axes          | プロダクト固有のコンテキストから導出される評価軸。design taste interview の出力を反映                                                                                                                                                       |
| Scoring-Ready Schema           | 16 fields (axis_id, axis_name, layer, origin, intent, why_it_matters, score_scale, anchors, positive_signals, negative_signals, anti_patterns, evidence_required, weight, minimum_floor, refs, review_questions) を持つ評価軸の完全スキーマ |
| Design Taste Interview         | UI-bearing project の discussion で実施する必須ヒアリング。visual character, emotional tone, anti-preferences 等 9 項目を記録                                                                                                               |
| Trend/Reference Research       | UI-bearing project の discussion で実施する必須リサーチ。trend scan, freshness metadata, confidence, translation を記録                                                                                                                     |
| Static-First                   | prototyping のデフォルトモードとして static analysis を優先し、runtime check を optional にするアーキテクチャ                                                                                                                               |
| Full-Harness                   | prototyping の premium path。runtime check, render evidence, browser QA, calibration を含む完全ワークフロー                                                                                                                                 |
| Render Evidence                | prototyping で生成される画面キャプチャ等の visual evidence。CLI path から実際に capture/skip/fail を報告                                                                                                                                    |
| Browser QA                     | prototyping の full-harness path で実行される自動 QA。smoke, visual, interaction, accessibility の4 phase                                                                                                                                   |
| UI-Bearing Detection           | surface type classification による UI/UX sidecar 生成要否の判定。explicit surface > content heuristics fallback                                                                                                                             |
| Surface Type                   | プロジェクトの UI surface 分類。web-ui, mobile-ui, desktop-ui, mixed, non-ui の5種                                                                                                                                                          |
| DDS (Design Direction Summary) | discussion 03_Story-Workshop.md 内のデザイン方向性サマリ。v1.7.8 で sidecar に従属する bridge 役に降格                                                                                                                                      |
| Sidecar                        | discussion pack に付随する uiux/ ディレクトリ内の 11 artifact。UI-bearing project のみ生成                                                                                                                                                  |
| Migration Window               | 旧形式 → 新形式への移行猶予期間。window 内は warning、window 後は error                                                                                                                                                                     |
| Stale-Asset                    | migration window 内の旧形式 artifact。upgrade guidance 付きで validator warning を発行                                                                                                                                                      |
| Foundation-Only                | 内部モジュールは存在するが user-facing workflow としては未完成な実装状態                                                                                                                                                                    |
| Over-Fire                      | non-UI project 等で本来発火すべきでない validator が発火する不具合                                                                                                                                                                          |
