# Migration Guide: v1.4.38 → v1.5.0

## 概要

v1.5.0 は `/qfai-discuss` と `/qfai-require` を統合し、**`/qfai-discussion`** という単一スキルに集約するメジャーリリースです。

discussion pack は 15 ファイル構成で、従来 9 ファイルだった discuss pack と require pack の両方の役割をカバーします。

## Breaking Changes

### 1. config: `requireDir` → `discussionDir`

**`qfai.config.yaml`** のパス設定が変わります。

```yaml
# Before (v1.4.x)
paths:
  requireDir: ".qfai/require"

# After (v1.5.0)
paths:
  discussionDir: ".qfai/discussion"
```

TypeScript の `QfaiPaths` 型でも `requireDir` プロパティが `discussionDir` に置き換わっています。

### 2. スキル統合: `qfai-discuss` + `qfai-require` → `qfai-discussion`

| v1.4.x           | v1.5.0              |
| ---------------- | ------------------- |
| `/qfai-discuss`  | `/qfai-discussion`  |
| `/qfai-require`  | `/qfai-discussion`  |
| `.qfai/discuss/` | `.qfai/discussion/` |
| `.qfai/require/` | `.qfai/discussion/` |

### 3. discussion pack ファイル構成（15 ファイル）

```text
discussion-YYYYMMDDhhmmssSSS/
  01_Context.md
  02_Inception-Deck.md
  03_Story-Workshop.md

```

### 4. バリデーターコード変更

| v1.4.x                         | v1.5.0                            |
| ------------------------------ | --------------------------------- |
| `QFAI-RPACK-001..006`          | `QFAI-DPACK-001..008`             |
| `validateRequirePackReadiness` | `validateDiscussionPackReadiness` |

## 移行手順

### Step 1: `qfai init --force` を実行

```bash
npx qfai init --force
```

これにより新しい `qfai-discussion` スキルが配置され、旧 `qfai-discuss` / `qfai-require` スキルが削除されます。

### Step 2: config を更新

`qfai.config.yaml` で `requireDir` を `discussionDir` に変更します。

### Step 3: ディレクトリをリネーム

```bash
# 旧 discuss / require ディレクトリの内容を discussion に統合
mkdir -p .qfai/discussion
# 必要に応じて旧 pack の内容を移行
```

### Step 4: バリデーション実行

```bash
npx qfai validate
```

`QFAI-HYG-001` が旧ディレクトリを検出した場合はリネームしてください。

## 後方互換

- 旧 `discuss-*` / `require-*` ディレクトリは `repositoryHygiene` バリデーターが legacy として検出・警告します。
- `mermaidEnforcement` は `.qfai/discuss` と `.qfai/discussion` の両方をスキャン対象にしています。
- `reviewArtifacts` は `"discuss"` と `"discussion"` の両方を有効な target kind として受け入れます。
